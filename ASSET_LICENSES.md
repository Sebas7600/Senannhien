# Asset sources · Sen An Nhiên V3

The source code, scene construction, clothing, rig and animations are authored for this project. The following third-party assets are distributed locally; gameplay does not contact these services.

## Vietnamese granito benches · original project assets

The outdoor stone benches use original extruded/bevelled geometry, procedural PBR aggregate shading and original canvas lettering. No factory photographs, manufacturer logos or textures are distributed in these models. Reference URLs and observed construction/color details are documented in `RESEARCH_GHE_DA_VIET_NAM.md`.

## Bodhi courtyard tree and optimized bench resources · original project assets

The clustered crown, tapered trunk/roots, masonry ring, small altar, incense burner and offerings are original procedural geometry based on reference images supplied by the user. The optimized granito aggregate texture and lettering are generated once locally by project code, shared across bench instances and mipmapped. No additional external model, photograph or font file is bundled.

## Leaf clusters and vein surface · original project assets

The folded heart-shaped leaf meshes and the shared 256 × 256 vein/variation data texture are generated by project code from the user's visual brief. No external leaf image or model is bundled.

## Liên Thủy meditation cushions

The lotus-whorl woven top is an AI-generated image made with imagegen for this project, using the user's supplied cushion photograph as a material/style reference. The supplied product photo itself is not distributed as a game texture. The generated source is preserved in `artifacts/cushions/lien-thuy-original.png`; the runtime JPEG atlas combines it with a code-generated side weave. Cushion geometry, UV atlas packing and the shared procedural weave bump are project code. No manufacturer logo or product branding is included.

## Bronze bowl strike · synthesized project audio

`public/assets/audio/bow-bowl.mp3` is an original additive synthesis generated by `src/bowlSynthesis.ts`, informed by spectral resonance measurements of the user-supplied reference video. The video's film soundtrack, speech and music are not distributed in the game. FFmpeg from the npm package `@ffmpeg-installer/win32-x64` was used only as a local development tool to inspect the reference and encode the generated sample; its binary is not bundled in the game.

## User-supplied gate, bronze bell and dragon drum · 2026-11-04

`public/assets/courtyard/` derives from the three ZIP archives supplied by the user for integration: Cong_Tam_Quan_Hai_Trang_Thai, Chuong_Dong_Bong, Trong_Dinh_Rong. The models and their original artwork are user-supplied assets, not covered by the CC0 credits for other project assets. The web variants merge static material batches, compress geometry with Meshoptimizer (MIT), share/rescale embedded textures, and include reduced geometry versions. Both gate states are reproduced from the closed model and the measured hinge rotation of the supplied open model. The Maya source files and preview images are not served as runtime assets. Integration details and measured budgets are in CONG_CHUONG_TRONG.md.

The gate was subsequently replaced with the user's **Cong_Moi.zip** (Cong_Bai_Dinh_Dong.glb / Cong_Bai_Dinh_Mo.glb). Current `gate-bai-dinh-v1*.glb` and `bai-dinh-v1-*.jpg` derive from this replacement, retaining its five original 768px JPEG textures. The detailed web mesh retains all source triangles; identical PBR materials are deduplicated, static primitives are merged, and the low variant uses Meshoptimizer simplification. Old gate runtime files are no longer distributed. Bell and drum artwork is unchanged.

## User-supplied Quan Am statue · 2026-11-04

`public/assets/quan-am/quan-am-v1*.glb` derives from the user's `Quan_Am_Converted.fbx`. Sculpture geometry is user-supplied; it is not included under other assets' CC0 credits. Offline processing centers, orients, batches and simplifies the sculpture, preserves the supplied body normals, adds UVs and vertex colors, and rebuilds the dense lotus base as project-authored closed petals. Ivory jade veining, stone/bronze/ceramic surfaces, altar and decorative flowers are generated by project code, with no external image assets or AI-generated bitmap textures. Meshoptimizer is used under its MIT license, only as an offline encoder (existing runtime decoder retained). See QUAN_AM_BO_TAT.md for placement, interaction and budgets.

## User-supplied wooden broom and bodhi leaf photographs · 2026-11-05

`public/assets/sweeping/` derives from **Choi_Can_Go_Web (2).zip** and **La_Bo_De_Texture (2).zip**, supplied by the user for this game. The broom geometry, original vertex colors, wood texture and three leaf photographs are user-supplied artwork; they are not covered by the CC0 credits of other assets. Web variants batch/simplify/compress the broom and pack the three alpha-cutout leaf photographs into one WebP atlas. Two-hand rigging, contact, bristle recoil, UV atlas selection and the leaf fold mesh are project code. FFmpeg/libwebp is only an offline development encoder and is not distributed. See CHOI_VA_LA_BO_DE.md for budgets and reproduction.
